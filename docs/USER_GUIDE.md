# 使用指南 | User Guide

本指南介绍如何从首次打开应用开始，完成一次学术检索式生成、检查和使用。

## 1. 打开应用

在线入口：[AI 检索力](https://horacech.github.io/Information-Retrieval-Tool/)

首次进入时可以使用页面顶部的 **新手引导**。也可以通过主导航在以下页面间切换：

- **AI 智能检索式生成**：输入研究意图并生成检索式。
- **官方网址速查**：浏览内置的数据库、专利和标准平台入口。
- **项目介绍**：了解项目能力、工作流程、配置方式和相关文档。

## 2. 配置模型服务商

1. 打开页面顶部的 **设置**。
2. 在模型配置中选择服务商。
3. 填入该服务商提供的 API Key。
4. 选择要使用的模型。
5. 点击 **测试连接**，成功后保存配置。

支持预设 Gemini、DeepSeek、SiliconFlow、Kimi / Moonshot、Zhipu GLM、DashScope / Qwen、OpenAI 和 OpenRouter；也可以添加自定义 OpenAI-compatible endpoint。

**费用提醒：** 模型调用可能产生费用，具体价格和额度由服务商决定。请在服务商控制台确认计费方式和剩余额度。

### 语音输入

语音转文字功能使用 Gemini。即使主要检索式生成使用其他服务商，使用语音输入时仍需要有效的 Gemini API Key，并允许浏览器访问麦克风。

## 3. 设置检索任务

在 AI 检索工作区：

- **目标数据库**：选择实际准备使用的平台。不同数据库对字段代码、布尔算符、短语和位置算符的支持可能不同。
- **语种偏好**：选择中英双语、仅中文或仅英文。
- **检索模板**：根据任务选择通用学术、PICO、工程问题/方法/场景、专利三要素、查全优先或查准优先等框架。
- **对比模式**：需要比较生成质量时，启用双模型对比并分别选择模型 A 和模型 B。

## 4. 描述研究意图

尽量描述清楚：

- 研究对象是什么？
- 要解决什么问题？
- 关注哪些方法、材料、技术或应用场景？
- 是否有时间、地区、人群或其他限制？
- 希望优先提高查全率，还是查准率？

例如：

> 面向大型地面光伏电站，调研用于光伏板表面灰尘清洁的机器人技术，重点关注移动机构、水射流清洁方式、清洁效率和组件安全性。

比只输入“光伏清洁机器人”更具体的研究意图，通常更有利于生成可检查的概念分面。

## 5. 检查生成结果

生成后建议依次检查：

1. **核心关键词**：是否准确表达研究对象和技术问题？
2. **同义词扩展**：是否包含常见缩写、英文全称、专业术语和必要的上下位词？是否引入无关概念？
3. **布尔检索式**：同一概念组内是否合理使用 OR，不同概念组之间是否合理使用 AND，是否需要 NOT 排除词？
4. **字段检索式**：字段代码是否符合目标数据库的实际语法？
5. **语法提示与逻辑树**：括号、引号、算符和嵌套关系是否正确？
6. **模型解释**：检查模型对概念关系和检索策略的说明，不要把解释文字直接当作数据库规则。

生成结果是辅助草案，不是数据库官方认证的检索式。正式使用前应在目标平台中验证。

## 6. 复制并执行检索

- 使用结果区域的复制功能复制布尔检索式或字段检索式。
- 使用一键检索或官方网址速查打开目标数据库。
- 根据数据库实际检索框和字段选项粘贴、调整并执行。
- 记录实际使用的检索日期、数据库、检索字段和最终检索式，便于复现。

本工具负责生成和辅助检查检索策略；实际文献结果、筛选和全文获取由目标数据库及研究者完成。

## 7. 其他功能

- **模板库**：管理可复用的检索框架。
- **双模型对比**：比较不同模型的关键词覆盖与检索式结构。
- **语义词条调整**：按需要包含或排除扩展关键词。
- **反馈与二轮优化**：对结果评分并描述需要改进的地方。
- **历史记录**：恢复此前生成的检索式。
- **性能统计**：查看本地记录的调用次数、响应耗时和 Token 使用情况。
- **官方网址速查**：按平台类别查找常用数据库入口。

## 8. 隐私、密钥与数据流向

当前应用为静态前端应用，没有自建模型代理后端。

- API Key 与部分配置存储在当前浏览器的 localStorage 中，应用不会对其进行加密。
- 检索提示词和语音转写请求会发送给所选择的模型服务商。
- 模型服务商的数据保留和使用政策由服务商决定。
- 不要在公共设备保存 API Key，也不要输入不适合发送给模型服务商的敏感资料。
- 公开部署不需要在 GitHub Actions 或 Vite 构建中注入个人 API Key。

如需清除密钥，可在设置中清除对应服务商配置，或清除浏览器中该站点的本地数据。

## 9. 常见问题

### 测试连接失败

检查 API Key 是否正确、模型名称是否有效、账户是否有额度，以及网络或服务商接口是否可用。自定义 endpoint 需要符合对应服务商的 API 格式。

### 生成请求失败或超时

可尝试更换模型、缩短输入、稍后重试，或查看服务商控制台的错误和额度信息。

### 数据库不接受生成的检索式

不同平台的字段、算符和位置检索语法可能不同。确认目标数据库选择正确，并对照该平台官方帮助文档修订检索式。

### 为什么应用没有直接显示论文列表？

本项目生成检索策略并提供数据库入口，不负责抓取、索引或存储学术文献。请在目标数据库中执行检索。
