# 使用指南 | User Guide

本指南介绍如何从首次打开应用开始，完成一次学术检索式生成、检查和使用。

## 1. 打开应用

在线入口：[AI 检索力](https://horacech.github.io/Information-Retrieval-Tool/)

首次进入时可以使用页面顶部的 **新手引导**。也可以通过主导航在以下页面间切换：

- **AI 智能检索式生成**：输入研究意图并生成检索式。
- **官方网址速查**：浏览内置的数据库、专利和标准平台入口。
- **项目介绍**：了解项目能力、工作流程、配置方式和相关文档。

## 2. 配置可信模型服务

本指南描述待审查的 Release Candidate，不表示线上版本已经更新。

1. 由服务维护者启动可信服务，在服务端配置所需供应商密钥；GitHub Pages 不自带推理服务。
2. 打开页面 **设置**，填入可信服务地址，并选择服务支持且已配置的供应商与模型。
3. 点击 **测试连接**，连接正常后保存。

页面不接受供应商 API Key，也不提供浏览器直连兼容入口。服务地址不可包含密码或令牌。模型调用可能产生费用，额度、鉴权与数据政策由服务维护者和上游供应商管理。未配置服务时不能进行模型生成，不会自动转到其他目的地。

### 语音输入

在研究意图输入区的 **语音识别引擎** 下拉框中选择 Gemini、OpenAI、Deepgram 或 Whisper 本地服务。它独立于检索式生成模型，并在当前浏览器记住选择。

- **Gemini**：通过配置的可信语音服务转写，密钥由服务维护者设置，浏览器不接收该密钥。
- **OpenAI / Deepgram**：需要另行配置的可信服务端代理；不要在前端或浏览器存储中填入语音专用密钥。
- **Whisper 本地服务**：需要自行运行本地 runtime 和配置代理地址；选择菜单不会安装模型或启动服务。

允许浏览器访问麦克风后，点击语音按钮开始录音，完成后选择 **完成并转写**，结果会进入研究意图输入框；选择 **取消** 放弃当前录音。转写后请核对专业术语再生成检索式。引擎不可用时不会自动切换到其他服务商。

#### 本地 Whisper 与 GPU

RC 包含独立 runtime，运行前请阅读 [runtime README](../services/speech-whisper/README.md) 和 [GPU 指南](WHISPER_GPU.md)。是否已合并或发布应核对实时 PR 与部署记录。CPU 默认 small / int8 / 单路并发；GPU 模式需 Windows 11、WSL2、兼容 NVIDIA 驱动、Docker GPU passthrough 和独立 GPU Compose 配置。不要把云端 CI 的模拟结果视为本机 RTX 验收。

本地未认证服务应仅绑定 `127.0.0.1`。GitHub Pages 的 HTTPS 页面连接本地服务还可能受到浏览器的本地网络权限、混合内容或组织策略限制，需要在实际 Chrome / Edge 上验证；不要为绕过限制而关闭浏览器安全保护。代理配置、协议与安全边界见 [Speech Providers](SPEECH_PROVIDERS.md)。

## 3. 设置检索任务

在 AI 检索工作区：

- **目标数据库**：选择实际准备使用的平台。不同数据库对字段代码、布尔算符、短语和位置算符的支持可能不同。
- **语种偏好**：选择中英双语、仅中文或仅英文。
- **检索模板**：根据任务选择通用学术、PICO、工程问题/方法/场景、专利三要素、查全优先或查准优先等框架。
- **对比模式**：需要比较生成质量时，启用双模型对比并分别选择模型 A 和模型 B。

## 4. 描述研究意图

尽量描述清楚：

- 研究对象是什么？
- 要解决什么问题？
- 关注哪些方法、材料、技术或应用场景？
- 是否有时间、地区、人群或其他限制？
- 希望优先提高查全率，还是查准率？

例如：

> 面向大型地面光伏电站，调研用于光伏板表面灰尘清洁的机器人技术，重点关注移动机构、水射流清洁方式、清洁效率和组件安全性。

比只输入“光伏清洁机器人”更具体的研究意图，通常更有利于生成可检查的概念分面。

## 5. 检查生成结果

生成后建议依次检查：

1. **核心关键词**：是否准确表达研究对象和技术问题？
2. **同义词扩展**：是否包含常见缩写、英文全称、专业术语和必要的上下位词？是否引入无关概念？
3. **布尔检索式**：同一概念组内是否合理使用 OR，不同概念组之间是否合理使用 AND，是否需要 NOT 排除词？
4. **字段检索式**：字段代码是否符合目标数据库的实际语法？
5. **语法提示与逻辑树**：括号、引号、算符和嵌套关系是否正确？
6. **模型解释**：检查模型对概念关系和检索策略的说明，不要把解释文字直接当作数据库规则。

生成结果是辅助草案，不是数据库官方认证的检索式。正式使用前应在目标平台中验证。

### 检索式结构检查：能检查什么，不能证明什么

应用检查括号、短语引号、悬空/连续算符、字段值缺失和可疑的相邻检索项。单引号和双引号短语均计入短语统计。通过检查只表示基础结构未发现覆盖范围内的错误，不代表字段代码、位置/截词算符或目标数据库实时语法一定兼容。

“规范化标点”只转换可安全识别的全角语法标点，不会自动补齐括号/引号，也不会删除、插入或替换 AND / OR / NOT。请在目标数据库中验证最终检索式。

## 6. 复制并执行检索

- 使用结果区域的复制功能复制布尔检索式或字段检索式。
- 使用一键检索或官方网址速查打开目标数据库。
- 根据数据库实际检索框和字段选项粘贴、调整并执行。
- 记录实际使用的检索日期、数据库、检索字段和最终检索式，便于复现。

本工具负责生成和辅助检查检索策略；实际文献结果、筛选和全文获取由目标数据库及研究者完成。

## 7. 其他功能

- **模板库**：管理可复用的检索框架。
- **双模型对比**：比较不同模型的关键词覆盖与检索式结构。
- **语义词条调整**：按需要包含或排除扩展关键词。
- **反馈与二轮优化**：对结果评分并描述需要改进的地方。
- **历史记录**：恢复此前生成的检索式。
- **性能统计**：查看本地记录的调用次数、响应耗时和 Token 使用情况。
- **官方网址速查**：按平台类别查找常用数据库入口。
- **离线官方网址速查**：导出单文件 HTML，内置网址目录和拼音索引可离线查询；访问外部数据库和使用 AI 生成仍需网络。
  - 自定义文件入口只保存文件名记录，不复制文件内容；请将对应文件与导出的 HTML 放在同一文件夹。

### 浅色 / 深色模式

在顶部设置菜单的外观选项中选择浅色或深色。主题偏好保存在当前浏览器；清除站点数据会重置该偏好。小屏幕下可横向滚动主导航，表格和检索式区域可在各自容器中滚动。

## 8. 隐私、密钥与数据流向

当前 RC 前端为静态应用；GitHub Pages 不托管模型服务。文本生成和所有语音引擎均访问配置的可信服务。

- 供应商密钥只放在可信服务端，页面不接受或保存 API Key；服务地址和模型偏好保存在当前浏览器。
- 旧版本可能曾保存密钥。升级时需清理旧凭据；如果页面提示无法访问存储，应使用浏览器站点数据管理完成清理，不能把失败当作成功。旧备份不受页面清理影响，曾暴露的密钥应向供应商撤销。
- 研究意图和录音发送到所配置的可信服务，由其联系上游供应商。请在录音前确认服务地址和数据政策。
- 不要提交敏感资料。共享设备上请清理本应用的历史和站点数据。
- 不在 GitHub Actions 或 Vite 构建中注入个人供应商密钥。

## 9. 常见问题

### 测试连接失败

检查可信服务地址、服务是否启动、所选模型是否支持以及浏览器网络错误。供应商凭据与账户额度由服务维护者在服务端检查；不要将密钥发给前端或粘贴到错误报告中。

### 生成请求失败或超时

可尝试更换模型、缩短输入、稍后重试，或查看服务商控制台的错误和额度信息。

### 无法录音或转写失败

确认页面使用 HTTPS 或 localhost、系统麦克风正常、浏览器和操作系统均已授权麦克风。关闭其他占用麦克风的程序后再试。检查所选引擎及实际 endpoint，不要仅凭菜单可选就认为服务已配置。

代理连接失败时先检查服务是否启动、地址与端口是否正确；跨域失败时核对精确 Origin 配置。HTTP 413 通常表示上传过大，429 表示服务忙或限流；可缩短录音并等待后重试。取消、超时、断网和空音频应停止本次操作，恢复连接后重新录音。问题持续时提供脱敏错误、浏览器版本和引擎名称，不要附 API Key 或私人录音。

### 数据库不接受生成的检索式

不同平台的字段、算符和位置检索语法可能不同。确认目标数据库选择正确，并对照该平台官方帮助文档修订检索式。

### 为什么应用没有直接显示论文列表？

本项目生成检索策略并提供数据库入口，不负责抓取、索引或存储学术文献。请在目标数据库中执行检索。
